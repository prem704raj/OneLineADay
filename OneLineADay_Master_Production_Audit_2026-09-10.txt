## A. Executive Summary
=======================

RELEASE DECISION: NO-GO FOR PRODUCTION.

The app already has a useful micro-journal foundation, but the current build should not
be trusted with years of irreplaceable memories yet.

The most important confirmed problems are:

1. P0 — Restore is not atomic or failure-safe.
   File:
   app/src/main/java/com/onelineaday/dailydiary/viewmodel/JournalViewModel.kt
   Function: importBackup()
   It extracts attacker-controlled ZIP entries directly over live production database/media
   files while the Room singleton is open. There is no staging, integrity verification,
   rollback, archive format version, size limit, duplicate-entry protection, or canonical
   path validation.

2. P0 — Backup is not a trustworthy Room snapshot.
   File: JournalViewModel.kt
   Function: exportBackup()
   It copies journal_database, -wal and -shm files while Room remains open. A raw copy of
   a live WAL database is not a robust portable backup architecture.

3. P0 — Home edit can silently lose tags and additional media references.
   Files:
   ui/screens/HomeScreen.kt
   viewmodel/JournalViewModel.kt
   Home restores only content/mood/photoUri and calls saveEntry() without existing tags
   and full mediaUris. saveEntry() overwrites those fields with default empty lists.

4. P0 — Imported ZIP path traversal is possible inside the app sandbox.
   File: JournalViewModel.kt
   Function: importBackup()
   For example media/../../something becomes File(filesDir, "../../something").
   There is no canonical-path containment check.

5. P1 — Date rollover can write to yesterday after midnight.
   File: JournalViewModel.kt
   _selectedDate is initialized once with LocalDate.now(). The "today" Room Flow is also
   created for one LocalDate value and no midnight boundary refresh exists. A long-running
   process can continue saving to the old calendar day.

6. P1 — Multiple journals are not end-to-end isolated.
   File: JournalViewModel.kt
   setSelectedDate() and search() omit activeJournalId and repository methods default to
   "default". The data model supports journal IDs, but the UI has no complete journal
   manager/switcher and several consumers still assume the default journal.

7. P1 — Search/date observation accumulates long-lived Flow collectors.
   File: JournalViewModel.kt
   Every search keystroke and each setSelectedDate call launches a new collect() job with
   no cancellation/flatMapLatest.

8. P1 — Streak freeze calculation mutates inventory during ordinary reads.
   Files:
   data/JournalRepository.kt
   viewmodel/JournalViewModel.kt
   calculateStreak() calls onFreezesConsumed(), and loadData() invokes it whenever the
   entries Flow emits. Recalculation can drain freeze state.

9. P1 — Streak calculation contradicts its own intended logic.
   File: JournalRepository.kt
   It executes `streak += missedDays` while the immediately following comment states
   missed frozen days should not be added.

10. P1 — Voice notes collide across journals.
    File: ui/components/AudioAttachment.kt
    Filename is audio_<date>.m4a. journalId is not part of the identity and audio is not
    referenced by JournalEntry at all.

11. P1 — Media lifecycle is unsafe/incomplete.
    File: JournalViewModel.kt
    saveMediaToInternal() copies arbitrary bytes but forces .jpg/.mp4 extensions, may return
    a path when openInputStream() returned null, uses timestamp filenames, runs synchronously
    from Compose callbacks, and deletion leaves orphaned private files.

12. P1 — Widget bypasses App Lock privacy and journal selection.
    File: widget/JournalWidget.kt
    It displays actual diary text regardless of App Lock and queries default journal only.

13. P1 — Ad consent/CMP is missing.
    File: OneLineApp.kt initializes MobileAds and preloads full-screen ads at process start.
    Banner/native/interstitial/rewarded requests have no UMP canRequestAds() gate.

14. P1 — Billing version is unsupported for new Play submissions/updates.
    app/build.gradle.kts uses billing-ktx:6.1.0.
    In September 2026 PBL 6 is beyond its November 1, 2025 extension deadline.

15. P1 — Premium entitlement accepts unrelated products.
    File: billing/BillingManager.kt
    Any PURCHASED SUBS or INAPP result can set premium=true. purchase.products is not
    restricted to premium_monthly / premium_lifetime.

16. P1 — No automated tests and no CI.
    app/src/test and app/src/androidTest are absent; .github/workflows is absent.

17. P2 — Recents/screenshot privacy is not addressed.
    App Lock protects navigation UI, not Android Recents previews. No setRecentsScreenshotEnabled
    or FLAG_SECURE policy exists.

18. P2 — Localization is far from production quality.
    Many Kotlin files hardcode English. Arabic resources include semantic mistranslations,
    PLACEHOLDER0 leakage, English leftovers, and stale false privacy strings.

19. P2 — Accessibility failures exist.
    Several controls are explicitly 16/28/32/36dp; charts/heatmap lack semantic equivalents;
    light orange + white and teal foreground combinations fail normal-text contrast.

20. P2 — Product experience is too ad-heavy for a private journal.
    Native ads are inserted every two memories and interstitials appear every three save/edit
    events.

Positive foundations worth keeping:
- composite (date, journalId) primary key concept,
- no fallbackToDestructiveMigration(),
- minSdk 26 + targetSdk/compileSdk 36,
- FileProvider is not exported,
- no broad storage/location/contact/SMS permissions,
- notification text does not expose journal content,
- AppLockManager now supports biometric OR Android device credential correctly,
- PDF generation already uses Dispatchers.IO,
- internal media copying avoids long-term dependence on picker URIs,
- one shared JournalViewModel is used across main navigation.

## C. Architecture
==================

CURRENT ARCHITECTURE

Compose Screen
    |
    v
JournalViewModel (AndroidViewModel)
    |
    v
JournalRepository
    |
    v
JournalDao
    |
    v
Room journal_database

Side systems are called directly from UI:
- ReminderManager from Settings
- BillingManager singleton
- Ad manager singletons
- PdfExportHelper
- FileProvider
- Audio helpers
- Widget talks directly to Room
- backup/restore code lives inside JournalViewModel

GOOD:
- Core Room layering is simple and understandable.
- ViewModel is shared across Home/Timeline/Stats/Settings.
- No unnecessary enterprise clean-architecture framework.
- Flow is used for Room observation.

PROBLEMS:
- JournalViewModel owns too many unrelated responsibilities:
  CRUD + metrics + journal selection + media I/O + ZIP backup + restore + PDF delegation.
- SettingsScreen is ~46 KB and directly orchestrates notifications, auth, ads, PDF,
  backup, restore, locale, theme and billing.
- Data-domain side effects are mixed into calculations (streak freezes).
- File ownership is not represented in the DB.
- Audio ownership is completely outside the DB.
- active journal is inconsistently propagated.
- Ad/Billing singleton lifecycle is process-global without robust state models.
- no test seam (Clock, storage manager, billing adapter, consent adapter).

RECOMMENDED TARGET ARCHITECTURE — STILL SIMPLE

Compose
  -> JournalViewModel
      -> JournalRepository
          -> JournalDao / Room
      -> MediaStorageManager
      -> BackupArchiveManager
      -> Clock/DayProvider

Settings
  -> SettingsViewModel (optional split)
      -> ReminderScheduler
      -> AppLockManager
      -> BackupArchiveManager

Application-level
  -> AdsConsentManager -> Mobile Ads
  -> BillingRepository -> BillingClient

Do NOT add Firebase, Hilt, cloud sync, or a new backend merely to “modernize” the app.
Manual constructor wiring/singletons are sufficient at this project size if lifecycle is correct.

## E. KEEP AS-IS
================

1. KEEP composite key concept:
   JournalEntry primaryKeys = ["date", "journalId"].
   This is the correct base invariant for one daily entry per journal.

2. KEEP minSdk 26.
   It is reasonable and comfortably supports java.time without desugaring complexity.

3. KEEP targetSdk/compileSdk 36.
   This satisfies the current Google Play mobile target requirement.

4. KEEP the absence of fallbackToDestructiveMigration().
   Journal data must never be destroyed because a migration was omitted.

5. KEEP FileProvider android:exported="false".

6. KEEP scoped media selection/no broad storage permission.
   The app does not request READ/WRITE external storage.

7. KEEP RECORD_AUDIO permission being requested only when the user starts recording.

8. KEEP generic reminder copy.
   Current notifications do not print private journal entries.

9. KEEP AppLockManager’s central authenticator policy:
   BIOMETRIC_WEAK | DEVICE_CREDENTIAL.
   It avoids the prior lockout class of bug.

10. KEEP authentication before disabling App Lock.

11. KEEP PdfExportHelper generation on Dispatchers.IO.

12. KEEP one shared JournalViewModel across main navigation until the responsibilities
    are split intentionally.

13. KEEP local-first journal content architecture.
    No source evidence shows journal text being intentionally sent to a custom server.

14. KEEP explicit privacy V2 wording that states Room is not app-level encrypted.

15. KEEP premium suppression concept for ads; repair rewarded + consent rather than
    replacing the concept.


## F. Confirmed Bugs
===================

F-001 P0 — HOME EDIT DATA LOSS
File: ui/screens/HomeScreen.kt
Section: captured-entry Edit button + Save button
File: viewmodel/JournalViewModel.kt
Function: saveEntry()

Current:
- edit populates entryText, selectedMood, photoUri only.
- save calls saveEntry(entryText, selectedMood, photoUri).
- default mediaUris/tags are empty.
- existingEntry.copy() writes those empty lists.

Impact:
Tags and non-primary media disappear from the database when the user edits today’s line.

Reproduction:
1. Have an entry containing mediaUris=[A,B] and tags=["work"].
2. Open Home.
3. Tap Update Entry.
4. Change only text.
5. Save.
6. Entry now has only primary photo and tags=[].

Fix:
Carry the entire existing JournalEntry into draft state and submit all unchanged fields.
See CHANGE OLAD-001 in section AG.

F-002 P0 — ZIP PATH TRAVERSAL
File: JournalViewModel.kt
Function: importBackup()

Current:
File(filesDir, entry.name.removePrefix("media/"))

Attack:
media/../../shared_prefs/settings.xml

Impact:
Archive can write outside the intended media destination inside the app sandbox.

Fix:
Never extract directly to production paths. Stage first and require canonical target
containment + strict archive path allow-list.

F-003 P0 — RESTORE OVERWRITES LIVE ROOM FILES
File: JournalViewModel.kt
Function: importBackup()

Current:
production DB files are deleted/replaced while JournalDatabase singleton remains open.

Impact:
stale connections, undefined runtime state, partial restore, potential corruption.

Fix:
Stop raw DB replacement. Restore logical DTOs using one Room transaction after archive
validation and pre-copy new media to unique non-overwriting paths.

F-004 P0 — RESTORE SUCCESS BEFORE INTEGRITY VERIFICATION
Current:
after extraction completes, UI says “Backup restored successfully! Please restart the app.”

Missing:
- SQLite integrity check
- manifest/version validation
- expected row count validation
- media checksum validation
- schema compatibility validation
- rollback

F-005 P0 — BACKUP IS A LIVE SQLITE FILE COPY
File: JournalViewModel.kt
Function: exportBackup()

Current:
copies journal_database + matching sidecar files while Room is running.

Fix:
logical Room snapshot in a transaction -> versioned JSON manifest -> immutable files.

F-006 P1 — DEFAULT JOURNAL MISSING ON FRESH CURRENT-SCHEMA INSTALL
File: data/JournalDatabase.kt

The "default" Journal row is inserted only in MIGRATION_3_4.
Room fresh creation of schema version 4 does not run MIGRATION_3_4.
JournalViewModel nevertheless starts with activeJournalId="default".

Because no foreign key exists, entries can reference a journal row that does not exist.

Fix:
new schema version + onCreate/onOpen INSERT OR IGNORE default journal.

F-007 P1 — CROSS-JOURNAL DATE QUERY
File: JournalViewModel.kt
Function: setSelectedDate()

Calls repository.getEntryByDate(date) with default journal instead of active journal.

F-008 P1 — CROSS-JOURNAL SEARCH
File: JournalViewModel.kt
Function: search()

Calls repository.searchEntries(query) with default journal.

F-009 P1 — SEARCH FLOW COLLECTOR ACCUMULATION
Every keystroke launches a new perpetual collect job.

Impact:
stale results can overwrite fresh results; Room observers accumulate.

F-010 P1 — SELECTED-DATE COLLECTOR ACCUMULATION
Each setSelectedDate launches another perpetual collector with no cancellation.

F-011 P1 — MIDNIGHT DATE STALENESS
_selectedDate and current “today” observation are created from LocalDate.now() once.
No day boundary refresh exists.

Impact:
if app remains alive over midnight, a “Today” save can overwrite the previous calendar day.

F-012 P1 — STREAK FREEZE SIDE EFFECT ON READ
JournalRepository.calculateStreak calls onFreezesConsumed().
JournalViewModel invokes it whenever entries Flow emits.

A derived metric read must not mutate inventory.

F-013 P1 — STREAK MATH ADDS MISSED DAYS
The implementation runs `streak += missedDays`, contradicting its own comment.

F-014 P1 — AUDIO COLLISION ACROSS JOURNALS
File: AudioAttachment.kt
audio_<date>.m4a is global for the app.
Journal A and B on the same date address the same voice file.

F-015 P1 — AUDIO NOT OWNED BY JOURNALENTRY
No audio path/URI exists in JournalEntry.
Delete, backup, journal switching, restore and ownership cannot be modeled safely.

F-016 P1 — RECORDER LEAK ON START FAILURE
File: AudioRecorderHelper.kt
prepare()/start() catch does not release the recorder or reset the field.

F-017 P1 — AUDIO UI REPORTS RECORDING BEFORE START SUCCESS
AudioAttachment sets isRecording=true before recorder.startRecording() and helper returns Unit.

F-018 P1 — AUDIO UI REPORTS FILE EXISTS AFTER FAILED STOP
Stop click always sets fileExists=true and invokes onAudioSaved().

F-019 P1 — saveMediaToInternal FALSE SUCCESS
If contentResolver.openInputStream() returns null, no bytes are written but the function
still returns file.absolutePath.

F-020 P1 — MEDIA FILE TYPE LIE
Raw PNG/WEBP/HEIC bytes are copied to files ending .jpg.
Any video MIME is copied to a file ending .mp4 without transcoding.

F-021 P1 — TIMESTAMP MEDIA NAME COLLISION
System.currentTimeMillis() is not a uniqueness guarantee when multiple selected files are
copied in a tight loop.

F-022 P1 — DELETE DOES NOT DELETE OWNED PRIVATE FILES
deleteEntry()/deleteEntryByDate remove Room rows only.

Impact:
photos/videos/audio can remain indefinitely after “permanent” deletion.

F-023 P1 — REMOVING MEDIA LEAVES ORPHAN FILE

F-024 P1 — WIDGET LEAKS LOCKED DIARY TEXT

## H. Journal Data Integrity
============================

INVARIANT: ONE ENTRY PER DATE PER JOURNAL
GOOD:
JournalEntry uses composite primary key (date, journalId).

CONCERN:
The key order is date first, while most queries filter journalId. Add an explicit journalId
index rather than changing primary-key order and risking migration complexity.

CREATE
- uses getEntryByDateOnce(date, journalId) then writes.
- multiple rapid saves do not create duplicates due primary key.
- however UI has no isSaving guard and multiple coroutines can race/redundantly replace data.

EDIT
- historical edit preserves tags because updateEntry.copy() does not overwrite tags.
- Home edit does overwrite tags/media with empty defaults: confirmed data loss.

DELETE
- DB row is deleted.
- attachment files remain.
- lastDeletedEntry is in ViewModel RAM only.
- a second delete replaces the previous undo candidate.
- process death removes undo possibility.

MOVE BETWEEN JOURNALS
- no real UI.
- no explicit transaction to change composite key.
- if implemented later, changing journalId changes primary key and can conflict with an
  existing same-date target entry. Must require merge/cancel choice.

JOURNAL DELETE
- DAO exposes deleteJournal without foreign key.
- entries can be orphaned logically.
- no current UI protects default journal or non-empty journal.

SAME DATE IN TWO JOURNALS
Database allows it correctly.
Audio does not: both resolve audio_<same-date>.m4a.

PROCESS DEATH DURING SAVE
Room’s single SQL write is transactional, which is good.
Unsaved Compose draft is not durable.

RAPID SAVE
No duplicate rows, but no UI mutex/disable and multiple ad counters/messages can occur.

RECOMMENDATION
- schema v5 foreign key + index + audioUri
- explicit isSaving
- saved draft
- pure update path preserving all fields
- soft/visible undo before permanent file cleanup

## K. Restore & Archive Security
================================

CURRENT STATUS: ❌ P0.

REQUIRED PIPELINE:

1. Copy selected archive to private cache with compressed byte limit.
2. Open ZipFile.
3. Validate every entry name.
4. Reject:
   - absolute paths
   - `..`
   - backslash traversal
   - duplicate names
   - unknown top-level files
5. Enforce configurable:
   - compressed archive max
   - entry count max
   - individual uncompressed max
   - total uncompressed max
6. Require manifest.json for new format.
7. Validate appId and formatVersion.
8. Validate unique (date,journalId) keys.
9. Validate every entry’s journal exists.
10. Validate LocalDate and Mood values.
11. Verify SHA-256 and byte size for every attachment.
12. Copy restored media to NEW unique files; never overwrite current files.
13. Run one Room transaction:
    - delete current rows
    - insert restored journals
    - insert restored entries
    - verify expected counts/keys
14. Commit.
15. Only after commit:
    - update active journal
    - refresh UI
    - asynchronously clean unreferenced old managed files.
16. On any pre-commit failure:
    original DB and original files remain untouched.

CRASH SAFETY
Because restored files are new unique files and the only destructive logical change occurs
inside one SQLite transaction:
- crash before transaction -> original diary intact
- crash during transaction -> SQLite commit/rollback semantics
- commit -> DB references already-existing restored files
- cleanup failure -> orphan storage only, not diary loss

LEGACY BACKUP COMPATIBILITY
Do not simply drop the old raw-DB backup format.
Add a read-only LegacyBackupImporter:
- stage archive safely
- open staged DB, never production DB
- run PRAGMA integrity_check
- detect schema columns
- convert rows to logical DTOs
- map legacy media by basename
- import through the same new logical restore transaction.
If the legacy DB is inconsistent/corrupt, reject it while leaving current diary untouched.

## AC. Product / Monetization Review
====================================

1. STRONGEST DIFFERENTIATOR
Not “one line per day” by itself — multiple current Play apps use the exact proposition.
The strongest credible positioning is:
“the fastest private memory journal: one thought in seconds, then rediscover your life through
On This Day.”

2. IS ONE LINE STRONG ENOUGH?
Strong onboarding mechanism, weak standalone moat.
A direct competitor literally markets “One line a day. That’s the whole app,” and another
markets a 10-second one-sentence habit.

3. HAS FEATURE GROWTH MADE IT TOO COMPLEX?
Yes, in implementation and partially in UI.
Multiple journals + tags + photo/video + audio + streak freezes + achievements + four ad formats
make a “one thought, one day” product feel feature-heavy.

4. RETENTION FEATURES TO KEEP/STRENGTHEN
- On This Day across every previous year
- calm reminder
- timeline
- search
- reliable backup/export
- optional mood trends
- gentle milestones

5. DISTRACTIONS
- native ads between memories
- post-save interstitials
- streak-freeze mechanics
- overanimated gradient text
- premium CTA above the writing task
- multiple journals before single-journal reliability is excellent.

6. MULTIPLE JOURNALS
Hide from marketing/UI until isolation is fully correct.
Long term it can stay as an advanced feature, but it should not complicate the default flow.

7. VOICE/VIDEO
Keep as progressive-disclosure “memory extras,” not primary Home controls.
They can add emotional value, but text should remain the product identity.

8. ADS
Ads inside the personal timeline and immediately after saving should not exist.

9. PREMIUM
Good:
- themes
- advanced styled PDF
- richer visualization
- optional extra media capacity
- supporter badge/customization
Not premium:
- basic writing/read/search
- privacy
- basic backup/portable export

### 5. Make save single-flight

Replace saveEntry() with this version after schema v5 adds audioUri:

```kotlin
fun saveEntry(
    content: String,
    mood: Mood,
    photoUri: String? = null,
    mediaUris: List<String> = emptyList(),
    tags: List<String> = emptyList(),
    audioUri: String? = null
) {
    viewModelScope.launch {
        if (!saveMutex.tryLock()) return@launch

        _uiState.update {
            it.copy(isSaving = true)
        }

        try {
            refreshToday()

            val journalId = _activeJournalId.value
            val date = _selectedDate.value

            val existingEntry =
                repository.getEntryByDateOnce(
                    date = date,
                    journalId = journalId
                )

            val finalMediaUris =
                mediaUris
                    .filter { it.isNotBlank() }
                    .distinct()
                    .toMutableList()

            if (
                photoUri != null &&
                photoUri.isNotBlank() &&
                photoUri !in finalMediaUris
            ) {
                finalMediaUris.add(0, photoUri)
            }

            val normalizedTags =
                tags
                    .map { it.trim() }
                    .filter { it.isNotEmpty() }
                    .distinctBy { it.lowercase() }

            val now = System.currentTimeMillis()

            val entry =
                if (existingEntry != null) {
                    existingEntry.copy(
                        content = content,
                        mood = mood,
                        photoUri = photoUri,
                        mediaUris = finalMediaUris,
                        tags = normalizedTags,
                        audioUri = audioUri ?: existingEntry.audioUri,
                        updatedAt = now
                    )
                } else {
                    JournalEntry(
                        date = date,
                        journalId = journalId,
                        content = content,
                        mood = mood,
                        photoUri = photoUri,
                        mediaUris = finalMediaUris,
                        tags = normalizedTags,
                        audioUri = audioUri,
                        createdAt = now,
                        updatedAt = now
                    )
                }

            repository.saveEntry(entry)

            _uiState.update {
                it.copy(
                    message = "Entry saved!",
                    entrySaved = true
                )
            }
        } catch (t: Throwable) {
            _uiState.update {
                it.copy(message = "Could not save entry.")
            }
        } finally {
            _uiState.update {
                it.copy(isSaving = false)
            }

            saveMutex.unlock()
        }
    }
}
```

```kotlin
package com.onelineaday.dailydiary.data

import java.time.LocalDate

object StreakCalculator {

    fun current(
        entryDates: Set<LocalDate>,
        today: LocalDate,
        frozenDates: Set<LocalDate> =
            emptySet()
    ): Int {
        var cursor = today

        if (
            cursor !in entryDates &&
            cursor !in frozenDates
        ) {
            cursor =
                cursor.minusDays(1)
        }

        var count = 0

        while (true) {
            when {
                cursor in entryDates -> {
                    count++
                    cursor =
                        cursor.minusDays(1)
                }

                cursor in frozenDates -> {
                    // Preserve continuity but do not count a missed day.
                    cursor =
                        cursor.minusDays(1)
                }

                else -> return count
            }
        }
    }

    fun longest(
        entryDates: Set<LocalDate>
    ): Int {
        val dates =
            entryDates.sorted()

        if (dates.isEmpty()) {
            return 0
        }

        var longest = 1
        var current = 1

        for (
            index in
            1 until dates.size
        ) {
            if (
                dates[index] ==
                dates[index - 1]
                    .plusDays(1)
            ) {
                current++
                longest =
                    maxOf(
                        longest,
                        current
                    )
            } else {
                current = 1
            }
        }

        return longest
    }
}
```

```kotlin
            mediaRecorder = null
            isRecording = false

            runCatching {
                if (outputFile.exists()) {
                    outputFile.delete()
                }
            }

            Result.failure(t)
        }
    }

    fun stopRecording(
        outputFile: File
    ): Result<File> {
        val recorder =
            mediaRecorder
                ?: return Result.failure(
                    IllegalStateException(
                        "No recording is active."
                    )
                )

        if (!isRecording) {
            safelyRelease(recorder)
            mediaRecorder = null

            return Result.failure(
                IllegalStateException(
                    "Recorder state is invalid."
                )
            )
        }

        return try {
            recorder.stop()

            if (
                !outputFile.exists() ||
                outputFile.length() <= 0L
            ) {
                throw IllegalStateException(
                    "The recording file is empty."
                )
            }

            Result.success(outputFile)
        } catch (t: Throwable) {
            runCatching {
                if (outputFile.exists()) {
                    outputFile.delete()
                }
            }

            Result.failure(t)
        } finally {
            safelyRelease(recorder)
            mediaRecorder = null
            isRecording = false
        }

    fun cancelRecording(
        outputFile: File?
    ) {
        val recorder = mediaRecorder

        if (recorder != null) {
            // MediaRecorder.stop() may itself throw when too little audio
            // has been recorded, so cancellation must never depend on it.
            runCatching {
                if (isRecording) {

                    file.delete()
                }
            }
        }
    }

    private fun safelyRelease(
        recorder: MediaRecorder

        runCatching {
            recorder.reset()
        }

        runCatching {
            recorder.release()
```

```kotlin
package com.onelineaday.dailydiary.media

import android.content.Context
import android.net.Uri
import android.provider.OpenableColumns
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import java.io.File
import java.io.FileOutputStream
import java.util.Locale
import java.util.UUID

class MediaStorageManager(
    private val context: Context
) {

    private val mediaRoot =
        File(
            context.filesDir,
            "journal_media"
        ).apply {
            mkdirs()
        }

    suspend fun importVisualMedia(
        sourceUri: Uri
    ): Result<StoredMedia> =
        withContext(Dispatchers.IO) {
            runCatching {
                val resolver =
                    context.contentResolver

                val mimeType =
                    resolver
                        .getType(sourceUri)
                        ?.lowercase(Locale.ROOT)
                        ?: error(
                            "Unable to determine media type."
                        )

                require(
                    mimeType.startsWith("image/") ||
                    mimeType.startsWith("video/")
                ) {
                    "Only image and video files are supported."
                }

                val category =
                    if (
                        mimeType.startsWith("video/")
                    ) {
                        "video"
                    } else {
                        "image"
                    }

                val extension =
                    determineSafeExtension(
                        displayName =
                            queryDisplayName(
                                sourceUri
                            ),
                        mimeType =
                            mimeType
                    )

                val directory =
                    File(
                        mediaRoot,
                        category
                    ).apply {
                        mkdirs()
                    }

                val destination =
                    File(
                        directory,
                        "${UUID.randomUUID()}$extension"
                    )

                val input =
                    resolver.openInputStream(
                        sourceUri
                    ) ?: error(
                        "Selected media could not be opened."
                    )

                try {
                    input.use { source ->
                        FileOutputStream(
                            destination
                        ).use { output ->
                            source.copyTo(output)
                            output.fd.sync()
                        }
                    }

                    require(
                        destination.exists() &&
                        destination.length() > 0L
                    ) {
                        "Selected media was empty."
                    }

                    StoredMedia(
                        absolutePath =
                            destination.absolutePath,
                        mimeType =
                            mimeType,
                        byteSize =
                            destination.length()
                    )
                } catch (t: Throwable) {
                    runCatching {
                        destination.delete()
                    }

                    throw t
                }
            }
        }

    fun isManagedPath(
        path: String
    ): Boolean {
        val canonicalRoot =
            runCatching {
                mediaRoot.canonicalFile
            }.getOrNull()
                ?: return false

        val canonicalFile =
            runCatching {
                File(path).canonicalFile
            }.getOrNull()
                ?: return false

        return canonicalFile.path.startsWith(
            canonicalRoot.path +
                File.separator
        )
    }

    suspend fun deleteIfUnreferenced(
        path: String,
        referencedPaths: Set<String>
    ): Boolean =
        withContext(Dispatchers.IO) {
            if (
                path in referencedPaths ||
                !isManagedPath(path)
            ) {
                return@withContext false
            }

            runCatching {
                File(path).delete()
            }.getOrDefault(false)
        }

    private fun queryDisplayName(
        uri: Uri
    ): String? =
        context.contentResolver
            .query(
                uri,
                arrayOf(
                    OpenableColumns.DISPLAY_NAME
                ),
                null,
                null,
                null
            )
            ?.use { cursor ->
                if (cursor.moveToFirst()) {
                    cursor.getString(0)
                } else {
                    null
                }
            }

    private fun determineSafeExtension(
        displayName: String?,
        mimeType: String
    ): String {
        val fromName =
            displayName
                ?.substringAfterLast(
                    '.',
                    missingDelimiterValue = ""
                )
                ?.lowercase(Locale.ROOT)
                ?.takeIf {
                    it.matches(
                        Regex("[a-z0-9]{1,10}")
                    )
                }

        if (fromName != null) {
            return ".$fromName"
        }

        return when (mimeType) {
            "image/jpeg" -> ".jpg"
            "image/png" -> ".png"
            "image/webp" -> ".webp"
            "image/heic",
            "image/heif" -> ".heic"
            "image/gif" -> ".gif"
            "video/mp4" -> ".mp4"
            "video/webm" -> ".webm"
            "video/3gpp" -> ".3gp"
            else -> ".bin"
        }
    }
}

    val byteSize: Long
```

```kotlin
                                ?.takeIf {
                                    it.startsWith("/")
                                }
                                ?.let {
                                    descriptorFor(
                                        it,
                                        BackupFileKind.MEDIA
                                    ).id
                                }

                        val mediaIds =
                            entry.mediaUris
                                .filter {
                                    it.startsWith("/")
                                }
                                .distinct()
                                .map {
                                    descriptorFor(
                                        it,
                                        BackupFileKind.MEDIA
                                    ).id
                                }

                        val audioId =
                            entry.audioUri
                                ?.takeIf {
                                    it.startsWith("/")
                                }
                                ?.let {
                                    descriptorFor(
                                        it,
                                        BackupFileKind.AUDIO
                                    ).id
                                }

                        BackupEntryDto(
                            date =
                                entry.date.toString(),
                            journalId =
                                entry.journalId,
                            content =
                                entry.content,
                            mood =
                                entry.mood.name,
                            photoFileId =
                                photoId,
                            mediaFileIds =
                                mediaIds,
                            tags =
                                entry.tags,
                            audioFileId =
                                audioId,
                            isPinned =
                                entry.isPinned,
                            createdAt =
                                entry.createdAt,
                            updatedAt =
                                entry.updatedAt
                        )
                    }

                val manifest =
                    BackupManifest(
                        formatVersion =
                            FORMAT_VERSION,
                        appId =
                            APP_ID,
                        databaseSchemaVersion =
                            JournalDatabase.VERSION,
                        createdAtEpochMs =
                            System.currentTimeMillis(),
                        journals =
                            snapshot.journals.map {
                                BackupJournalDto(
                                    id = it.id,
                                    name = it.name,
                                    colorHex =
                                        it.colorHex,
                                    createdAt =
                                        it.createdAt
                                )
                            },
                        entries =
                            entryDtos,
                        files =
                            sourceToDescriptor
                                .values
                                .toList()
                    )

                require(
                    manifest.files
                        .sumOf {
                            it.byteSize
                        } <=
                        MAX_EXPANDED_BYTES
                ) {
                    "Backup exceeds the supported expanded size."
                }

                val exportDir =
                    File(
                        context.cacheDir,
                        "journal_exports"
                    ).apply {
                        mkdirs()
                    }

                val output =
                    File(
                        exportDir,
                        "OneLineADay_${System.currentTimeMillis()}.olad.zip"
                    )

                ZipOutputStream(
                    BufferedOutputStream(
                        FileOutputStream(
                            output
                        )
                    )
                ).use { zip ->
                    zip.putNextEntry(
                        ZipEntry(
                            "manifest.json"
                        )
                    )

                    zip.write(
                        gson.toJson(
                            manifest
                        ).toByteArray(
                            Charsets.UTF_8
                        )
                    )

                    zip.closeEntry()

                    sourceToDescriptor
                        .forEach {
                                sourcePath,
                                descriptor ->

                            zip.putNextEntry(
                                ZipEntry(
                                    descriptor.archivePath
                                )
                            )

                            FileInputStream(
                                File(sourcePath)
                            ).use {
                                input ->
                                input.copyTo(zip)
                            }

                            zip.closeEntry()
                        }
                }

                require(
                    output.length() <=
                        MAX_ARCHIVE_BYTES
                ) {
                    output.delete()
                    "Backup archive is too large."
                }

                val uri =
                    FileProvider.getUriForFile(
                        context,
                        "${context.packageName}.provider",
                        output
                    )

                BackupExportResult.Success(
                    uri = uri,
                    file = output
                )
            }.getOrElse {
                BackupExportResult.Failure(
                    reason =
                        it.message
                            ?: "Backup failed."
                )
            }
        }

    suspend fun restoreBackup(
        sourceUri: Uri
    ): BackupRestoreResult =
        withContext(Dispatchers.IO) {
            val session =
                UUID.randomUUID()
                    .toString()

            val stagingDirectory =
                File(
                    context.cacheDir,
                    "restore/$session"
                )

            val restoredFilesDirectory =
                File(
                    context.filesDir,
                    "journal_media/restored/$session"
                )

            var databaseCommitted =
                false

            try {
                stagingDirectory.mkdirs()
                restoredFilesDirectory.mkdirs()

                val stagedArchive =
                    File(
                        stagingDirectory,
                        "input.zip"
                    )

                copyUriWithLimit(
                    sourceUri =
                        sourceUri,
                    destination =
                        stagedArchive,
                    maxBytes =
                        MAX_ARCHIVE_BYTES
                )

                val validated =
                    validateArchive(
                        stagedArchive
                    )

                val restoredPathById =
                    mutableMapOf<
                        String,
                        String
                    >()

                ZipFile(
                    stagedArchive
                ).use { zip ->
                    validated.manifest
                        .files
                        .forEach {
                                descriptor ->

                            val zipEntry =
                                zip.getEntry(
                                    descriptor.archivePath
                                )
                                    ?: error(
                                        "A referenced attachment is missing."
                                    )

                            val extension =
                                descriptor
                                    .archivePath
                                    .substringAfterLast(
                                        '.',
                                        "bin"
                                    )
                                    .takeIf {
                                        it.matches(
                                            Regex(
                                                "[A-Za-z0-9]{1,10}"
                                            )
                                        )
                                    }
                                    ?: "bin"

                            val destination =
                                File(
                                    restoredFilesDirectory,
                                    "${descriptor.id}.$extension"
                                )

                            zip.getInputStream(
                                zipEntry
                            ).use { input ->
                                FileOutputStream(
                                    destination
                                ).use {
                                    output ->

                                    input.copyTo(
                                        output
                                    )

                                    output.fd.sync()
                                }
                            }

                            require(
                                destination.length() ==
                                    descriptor.byteSize
                            ) {
                                "Attachment size validation failed."
                            }

                            require(
                                sha256(destination)
                                    .equals(
                                        descriptor.sha256,
                                        ignoreCase = true
                                    )
                            ) {
                                "Attachment checksum validation failed."
                            }

                            restoredPathById[
                                descriptor.id
                            ] =
                                destination.absolutePath
                        }
                }

                val journals =
                    validated.manifest
                        .journals
                        .map {
                            Journal(
                                id = it.id,
                                name = it.name,
                                colorHex =
                                    it.colorHex,
                                createdAt =
                                    it.createdAt
                            )
                        }

                require(
                    journals.isNotEmpty()
                ) {
                    "Backup contains no journals."
                }

                val journalIds =
                    journals.map {
                        it.id
                    }.toSet()

                require(
                    journalIds.size ==
                        journals.size
                ) {
                    "Duplicate journal IDs were found."
                }

                val seenEntryKeys =
                    hashSetOf<String>()

                val entries =
                    validated.manifest
                        .entries
                        .map {
                                dto ->

                            require(
                                dto.journalId in
                                    journalIds
                            ) {
                                "Entry references an unknown journal."
                            }

                            val date =
                                LocalDate.parse(
                                    dto.date
                                )

                            val key =
                                "${dto.journalId}|$date"

                            require(
                                seenEntryKeys.add(key)
                            ) {
                                "Duplicate entry date/journal pair."
                            }

                            val mood =
                                runCatching {
                                    Mood.valueOf(
                                        dto.mood
                                    )
                                }.getOrElse {
                                    error(
                                        "Unsupported mood value."
                                    )
                                }

                            val photoPath =
                                dto.photoFileId
                                    ?.let {
                                        restoredPathById[it]
                                            ?: error(
                                                "Missing photo reference."
                                            )
                                    }

                            val mediaPaths =
                                dto.mediaFileIds
                                    .map {
                                        fileId ->
                                        restoredPathById[
                                            fileId
                                        ] ?: error(
                                            "Missing media reference."
                                        )
                                    }

                            val audioPath =
                                dto.audioFileId
                                    ?.let {
                                        restoredPathById[it]
                                            ?: error(
                                                "Missing audio reference."
                                            )
                                    }

                            JournalEntry(
                                date = date,
                                journalId =
                                    dto.journalId,
                                content =
                                    dto.content,
                                mood = mood,
                                photoUri =
                                    photoPath,
                                mediaUris =
                                    mediaPaths,
                                tags =
                                    dto.tags,
                                audioUri =
                                    audioPath,
                                isPinned =
                                    dto.isPinned,
                                createdAt =
                                    dto.createdAt,
                                updatedAt =
                                    dto.updatedAt
                            )
                        }

                val dao =
                    database.journalDao()

                database.withTransaction {
                    dao.deleteAllEntriesForRestore()
                    dao.deleteAllJournalsForRestore()

                    dao.insertJournalsForRestore(
                        journals
                    )

                    dao.insertEntriesForRestore(
                        entries
                    )

                    check(
                        dao.getJournalCountOnce() ==
                            journals.size
                    ) {
                        "Journal verification failed."
                    }

                    check(
                        dao.getTotalEntryCountOnce() ==
                            entries.size
                    ) {
                        "Entry verification failed."
                    }
                }

                databaseCommitted = true

                BackupRestoreResult.Success(
                    restoredJournals =
                        journals.size,
                    restoredEntries =
                        entries.size
                )
            } catch (t: Throwable) {
                if (!databaseCommitted) {
                    runCatching {
                        restoredFilesDirectory
                            .deleteRecursively()
                    }
                }

                BackupRestoreResult.Failure(
                    reason =
                        t.message
                            ?: "Restore failed."
                )
            } finally {
                runCatching {
                    stagingDirectory
                        .deleteRecursively()
                }
            }
        }

    private fun validateArchive(
        archive: File
    ): ValidatedBackup {
        ZipFile(archive).use {
            zip ->

            val seenNames =
                hashSetOf<String>()

            var entryCount = 0
            var expandedBytes = 0L

            val enumeration =
                zip.entries()

            while (
                enumeration.hasMoreElements()
            ) {
                val entry =
                    enumeration.nextElement()

                entryCount++

                require(
                    entryCount <=
                        MAX_ZIP_ENTRIES
                ) {
                    "Too many archive entries."
                }

                val name =
                    validateArchivePath(
                        entry.name
                    )

                require(
                    seenNames.add(name)
                ) {
                    "Duplicate archive entry."
                }

                if (entry.isDirectory) {
                    continue
                }

                val size =
                    entry.size

                require(
                    size >= 0L
                ) {
                    "Archive entry has an unknown size."
                }

                require(
                    size <=
                        MAX_SINGLE_FILE_BYTES
                ) {
                    "Archive entry is too large."
                }

                expandedBytes += size

                require(
                    expandedBytes <=
                        MAX_EXPANDED_BYTES
                ) {
                    "Expanded archive is too large."
                }

                require(
                    name ==
                        "manifest.json" ||
                    name.matches(
                        Regex(
                            """files/[0-9a-fA-F-]{36}\.[A-Za-z0-9]{1,10}"""
                        )
                    )
                ) {
                    "Unsupported archive path."
                }
            }

            val manifestEntry =
                zip.getEntry(
                    "manifest.json"
                )
                    ?: error(
                        "Backup manifest is missing."
                    )

            val json =
                zip.getInputStream(
                    manifestEntry
                )
                    .bufferedReader(
                        Charsets.UTF_8
                    )
                    .use {
                        it.readText()
                    }

            val manifest =
                gson.fromJson(
                    json,
                    BackupManifest::class.java
                )
                    ?: error(
                        "Backup manifest is invalid."
                    )

            require(
                manifest.formatVersion ==
                    FORMAT_VERSION
            ) {
                "Unsupported backup format version."
            }

            require(
                manifest.appId ==
                    APP_ID
            ) {
                "Backup belongs to another application."
            }

            val fileIds =
                hashSetOf<String>()

            val filePaths =
                hashSetOf<String>()

            manifest.files
                .forEach {
                    descriptor ->

                    require(
                        fileIds.add(
                            descriptor.id
                        )
                    ) {
                        "Duplicate backup file ID."
                    }

                    require(
                        filePaths.add(
                            descriptor.archivePath
                        )
                    ) {
                        "Duplicate backup file path."
                    }

                    require(
                        descriptor.archivePath
                            in seenNames
                    ) {
                        "Backup references a missing file."
                    }

                    require(
                        descriptor.byteSize in
                            0..MAX_SINGLE_FILE_BYTES
                    ) {
                        "Invalid backup file size."
                    }

                    require(
                        descriptor.sha256
                            .matches(
                                Regex(
                                    "[0-9a-fA-F]{64}"
                                )
                            )
                    ) {
                        "Invalid backup checksum."
                    }
                }

            return ValidatedBackup(
                manifest = manifest
            )
        }
    }

    internal fun validateArchivePath(
        rawPath: String
    ): String {
        require(
            rawPath.isNotBlank()
        ) {
            "Blank archive path."
        }

        require(
            !rawPath.contains('\\')
        ) {
            "Backslash paths are rejected."
        }

        require(
            !rawPath.startsWith("/")
        ) {
            "Absolute archive paths are rejected."
        }

        require(
            !Regex(
                "^[A-Za-z]:"
            ).containsMatchIn(
                rawPath
            )
        ) {
            "Drive-qualified paths are rejected."
        }

        val segments =
            rawPath.split('/')

        require(
            segments.none {
                it == "." ||
                it == ".." ||
                it.isBlank()
            }
        ) {
            "Path traversal is rejected."
        }

        return rawPath
    }

    private fun copyUriWithLimit(
        sourceUri: Uri,
        destination: File,
        maxBytes: Long
    ) {
        val input =
            context.contentResolver
                .openInputStream(
                    sourceUri
                )
                ?: error(
                    "Selected backup could not be opened."
                )

        input.use { source ->
            FileOutputStream(
                destination
            ).use { output ->
                val buffer =
                    ByteArray(
                        DEFAULT_BUFFER_SIZE
                    )

                var total = 0L

                while (true) {
                    val read =
                        source.read(buffer)

                    if (read < 0) {
                        break
                    }

                    total += read

                    require(
                        total <=
                            maxBytes
                    ) {
                        "Backup archive exceeds the supported size."
                    }

                    output.write(
                        buffer,
                        0,
                        read
                    )
                }

                output.fd.sync()
            }
        }
    }

    private fun sha256(
        file: File
    ): String {
        val digest =
            MessageDigest.getInstance(
                "SHA-256"
            )

        BufferedInputStream(
            FileInputStream(file)
        ).use { input ->
            val buffer =
                ByteArray(
                    DEFAULT_BUFFER_SIZE
                )

            while (true) {
                val read =
                    input.read(buffer)

                if (read < 0) {
                    break
                }

                digest.update(
                    buffer,
                    0,
                    read
                )
            }
        }

        return digest
            .digest()
            .joinToString("") {
                byte ->
                "%02x".format(byte)
            }
    }
}
```

IMPORTANT PRODUCTION CORRECTION:
The above current-format restore makes the destructive logical replacement inside one Room
transaction and never overwrites SQLite files. That gives transactional DB rollback.

However, after DB commit succeeds, the newly restored files must NOT be deleted. Therefore:
- on success, keep `restoredFilesDirectory`
- cleanup only the old files that are no longer referenced, after obtaining the final reference set.

If post-commit cleanup fails, report restore success with a storage-cleanup warning; do not
roll back the diary merely because old orphan cleanup failed.

LEGACY BACKUP SUPPORT
The current released/old source created raw `db/journal_database*` archives. Existing user
backups must not be abandoned silently.

CREATE:
`backup/LegacyBackupImporter.kt`

Required implementation contract:
1. Apply the same compressed/expanded byte and path checks.
2. Extract ONLY into a private staging directory.
3. Never place extracted DB/WAL/SHM in `context.getDatabasePath(...)`.
4. Open the staged DB separately using Android SQLiteDatabase read-only APIs.
5. Run:
   `PRAGMA quick_check`
   and require result `ok`.
6. Inspect `PRAGMA table_info(journal_entries)` and `PRAGMA table_info(journals)`.
7. Accept only known legacy schema shapes.
8. Convert rows to current DTOs.
9. Match staged `media/`, `photos/`, `audio/` files by basename.
10. Copy them into NEW UUID managed destinations.
11. Feed converted data into the same one-transaction logical restore.
12. Any error leaves the current diary untouched.

Do NOT reuse the old direct extraction code.

Until that importer has automated fixtures for v1/v2/v3/v4 backups:
- keep legacy restore labeled BETA in pre-release builds, or
- disable legacy restore rather than risk data loss.
